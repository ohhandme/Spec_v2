## 唯一干预

- 冻结 F seed42/43/44 的完整训练后 checkpoint、Target、Draft、边端本地状态、固定 val 前缀、目标续文、解码与统计程序。保留真实 F 结果作为原件，不重训、不覆盖。
- 对每个固定窗口，先以原 F 路径计算其合法 8192 字节 FP32 云端概率消息。以 `(task_type, prior_accepted_count)` 分层；在各层内按稳定键 `(prompt_id, round_index)` 排序，为每个窗口选取**不同 prompt** 的确定性 donor。所有层已有至少 9 个不同 prompt；如果运行时无法为任一窗口找到不同 prompt，则正确性 gate 失败并停止。
- 将 donor 当前轮云端概率消息替代该窗口的云消息，其他普通协议 token、`corrected_prefix`、本地码、模型权重和评测路径不变。donor 只提供当轮已有 Target 状态产生的概率，不提供目标未来标签、未来 Target 隐藏状态或下轮信息。保持 8192 字节相同序列化/解码路径，消息必须有限、每组概率归一且来源 SHA 可追溯。
- 真实 F 与置换 F 两组均从相同纠正后前缀真实自回归生成最多 `L=8` 个 Draft token；独立 Target greedy AR 续文全 token、EOS/截断一致。比较同窗口草稿 token 是否变化，主指标 `A_probe(F)-A_probe(F_swap)`、辅助 `A_probe(F_swap)-A_probe(C)`。主集 427 窗口、64 提示；567 全窗口作敏感性分析。窗口先在提示内平均，再按提示配对做 2000 次 bootstrap，seed 固定 `20261031`。报告三训练 seed 各自结果及描述性跨 seed 汇总；不把多窗口当独立样本。

## Gate 与解释边界

先写独立脚本与测试，锁定真实源码 SHA；smoke 检查 donor 非本 prompt、分层相同、消息有效/8192 字节、实际交换发生、原 F 对照与已归档结果逐窗口一致、完整 Target 续文与原参考相同。任一失败须保存失败原件、修复隔离实现并重跑 smoke/GPU gate。正式验证不删除任何窗口，不改变 EOS/截断门槛，不重新选择 seed 或训练 checkpoint。

如果 F 与置换 F 草稿输出几乎完全相同，只说明当前 checkpoint 的云消息对实际决策影响很小；如果输出变化却不提高接受长度，优先诊断 CE 与连续接受长度错配或修复器扰动。此置换不能单独证明 Target 状态有效，也不是新的 H1 成功标准。它是 P1-B 诊断，不进入 P2、P3、封存 test 或速度/WAN 声明。若诊断后仍无稳定 D>C，写有证据的阴性/交接报告，按预注册有界规则决定停止方法扩展。
