## Question and scope

Test whether the valid Qwen3-8B Target hidden-state message gives the Qwen3-0.6B Draft a reproducible improvement in greedy consecutive acceptance length when the repair modules are trained on 3000 topic-balanced UltraChat prompts. This is a fixed-prefix mechanism pilot. It does not establish packed implementation correctness, WAN latency, or speedup.

The previous 64-prompt validation set influenced the decision to expand data. It is a historical diagnostic only. This run must select a new validation set and a new sealed test set before choosing the new training prompts. No old test result or new test output may inform training or selection.

## Paired comparison and budget

- Arms: A raw frozen Draft; B capacity-matched edge-only; C normal protocol-only repair; D same edge-side structure with the valid 8-byte Target feedback; E same D weights with legitimate cross-request message shuffling, including a stratum/history-matched control. The principal incremental comparisons are D−C and D−E.
- First candidate: CE-only, `prefix_weight=0`, LR `1e-4`, weight decay `0.01`, **seed 42 only** by the user's 2026-10-31 instruction. Each B/C/D arm receives the **same complete, no-replacement one-epoch training-window schedule**. Lock the actual step count from the fully collected train corpus and verify exposure hashes and initial edge weights across arms before examining the new validation results. This is exploratory and does not establish seed-stable benefit.
- Main metric: on identical corrected prefixes, genuinely autoregressive Draft proposals and independent Target greedy futures, count only the consecutive accepted Draft tokens from position 1. Primary set: full nonterminal 8-token windows; all windows are a sensitivity analysis. Aggregate within prompt, then use paired prompt-level bootstrap (2000 replicates, fixed resampling seed) for 95% CIs. Report per-stratum and macro results, all six strata's sample counts, D−C/D−E, full-token correctness, and actual compute/memory cost. CE alone is not an acceptance result.
